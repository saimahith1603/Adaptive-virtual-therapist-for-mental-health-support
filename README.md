# 🤖 AI-Driven Virtual Therapist

An intelligent mental health support system powered by AI, Machine Learning, and Natural Language Processing. This application leverages facial expression recognition, voice emotion analysis, and conversational AI to deliver Cognitive Behavioral Therapy (CBT)-based responses and personalized mental wellness support.
